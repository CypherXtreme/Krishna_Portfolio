About

I'm a backend engineer with experience building distributed systems and RESTful APIs. I specialize in async architectures, background job processing and database optimization using FastAPI, Django and PostgreSQL.

I've built real-world applications that handle payment verification, rate limiting and location-based queries, on a foundation of system design, async I/O patterns and containerized deployments.

Projects

Freelancer Milestone Payment System

Holds client payments until freelancers complete project milestones.

  • Built a FastAPI backend where client deposits stay locked until the freelancer completes a milestone.
  • Used PostgreSQL transactions with row-level locking to prevent double-spending when releasing milestone payments.
  • Implemented a dispute resolution workflow: both parties upload evidence and an admin reviews it before funds are released.
  • Automated payment release with Celery tasks, including a 7-day auto-release when the client is unresponsive.
  • Integrated the Razorpay Payout API to send released funds directly to freelancer bank accounts.

FastAPI, PostgreSQL, Celery, Razorpay

API Monetization & Metering Platform

Tracks API usage and enforces rate limits for developers.

  • Built a FastAPI proxy that forwards requests to other APIs and logs each call in MongoDB.
  • Optimized rate limiting with Redis, counting requests per API key and blocking keys that hit their limit.
  • Wrote hourly Celery jobs that total API calls for billing.
  • Indexed MongoDB queries on api_key and timestamp so they stay fast with large logs.
  • Used Docker Compose to run FastAPI, MongoDB, Redis and Celery together during development.

FastAPI, MongoDB, Redis, Celery, Docker Compose

Daily Wage Worker Matching Platform API

Connects day laborers with local employers in real time.

  • Built a FastAPI backend with endpoints for posting jobs and searching workers by skills and location.
  • Modeled a PostgreSQL schema with SQLAlchemy ORM covering worker profiles, job posts and application history.
  • Added the PostGIS extension to PostgreSQL so workers can find jobs near them.
  • Set up Celery workers to send SMS notifications without slowing down API responses.

FastAPI, PostgreSQL, PostGIS, SQLAlchemy, Celery
